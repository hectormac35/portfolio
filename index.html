DevOps · Observabilidad · Seguridad

Seguridad y resiliencia con observabilidad

Entorno dockerizado que provoca fallos reales (caída de la base de datos, fuerza bruta) y comprueba que el sistema los detecta, avisa por Telegram y se recupera solo, guardando evidencias de cada incidente.

  • Prometheus + Alertmanager + Grafana: 4 reglas (caída, errores 5xx, fuerza bruta y latencia p95) con avisos a Telegram.
  • Nginx endurecido: único punto de entrada, rate limiting, cabeceras de seguridad y /metrics solo interno.
  • Resiliencia: liveness y readiness separados, timeouts cortos y modo degradado sin filtrar detalles internos.
  • Chaos engineering: scripts que provocan el incidente, esperan las alertas y comprueban la recuperación.
  • Contenedores sin privilegios y de solo lectura; CI que valida reglas, Nginx, Alertmanager e imagen.

DevSecOps · HashiCorp Vault · PostgreSQL

Vault · credenciales dinámicas de base de datos

Una API en FastAPI que nunca conoce una contraseña fija: Vault le entrega usuarios de PostgreSQL temporales que caducan solos, se renuevan sin reiniciar la app y se pueden revocar al instante ante un incidente.

  • Database secrets engine + AppRole + Vault Agent: credenciales de 2 minutos como máximo, con solo SELECT e INSERT.
  • Demo de incidente: se revocan todas las credenciales y la API se recupera sola en 15 s, sin reinicios.
  • Aislamiento: la app no ve el secret_id ni tokens; Vault rota la contraseña del admin; PostgreSQL sin puertos expuestos.
  • CI con pytest, ShellCheck y una prueba de extremo a extremo que levanta Vault y PostgreSQL reales.
